Data-to-Dirt: Privacy Policy

Effective Date: October 2026

Data-to-Dirt is an educational sustainability platform that empowers students and classrooms to identify digital waste, reduce data storage footprints, and convert verified carbon savings into real-world reforestation efforts.

1. Data Collection & Access

Data-to-Dirt accesses file metadata (such as file names, sizes, and last modified dates) solely to identify potential dark data candidates (stale relics, heavy file bloat, and duplicates). We never read, inspect, or transfer private contents of files.

2. Google Drive Data Usage

When connecting Google Drive, permissions are utilized strictly to query file metadata for dark data evaluation and, upon authorized teacher confirmation, delete or trash files requested by the student.

3. Data Protection

We do not sell, rent, or share user data with third-party advertisers. All authentication and data handling adhere to strict role-based separation between student, teacher, and administrator accounts.
